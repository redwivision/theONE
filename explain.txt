 PART 2: THE PIZZA BOX (models/movie.dart)
================================================
This file defines the SHAPE of the pizza box. Every movie that comes from the
kitchen must fit inside this box perfectly.

CLASS: Movie
  - id: The unique serial number on the box (e.g., "tt0111161")
  - details: The actual pizza inside (a MovieDetails object)
  - Movie.fromJson(): When we receive a JSON package from the backend, this
    "factory" reads the JSON and unpacks it into a Movie object.
    It grabs json['movie_id'] for id, and hands json['movie_details'] to
    MovieDetails to handle.

CLASS: MovieDetails
  - title: The pizza's name (e.g., "The Shawshank Redemption")
  - year: When the pizza was baked (e.g., "1994")
  - posterUrl: A link to a photo of the pizza
  - plot: What the pizza tastes like (the plot summary)
  - type: Is this a pizza slice (movie) or a whole pizza party (series)?
  - runtime: How long it takes to eat (e.g., "142 min")
  - totalseason: How many pizza party nights (e.g., "4" seasons)
  - MovieDetails.fromJson(): Like Movie's factory, this one reads the INNER
    part of the JSON (json['movie_details']) and maps key names like 'Title',
    'Poster', 'Plot' to our Dart fields. The "?? 'N/A'" part is a safety net:
    if the field is missing, don't crash, just write "N/A".


================================================
 PART 3: THE DELIVERY APP (main.dart)
================================================
This is the ROOT of the app. Every Flutter app starts here.

void main() → runApp(MyApp()): This is the "Start the engine" button. Every
Dart program needs a main() function. runApp() tells Flutter "this is the
first screen to show."

CLASS: MyApp (StatelessWidget)
  - This never changes or has memory. It just launches the MaterialApp (the
    whole visual framework for the app) and points to HomePage as the first
    screen.
  - debugShowCheckedModeBanner: false → Hides the ugly red "DEBUG" banner
    from the top-right corner of the screen.

CLASS: HomePage (StatefulWidget)
  - This IS stateful. "State" means "memory." This screen needs to REMEMBER
    which movie it's currently showing and when to fetch a new one.
  - _movieFuture: This is a "IOU note." A Future<Movie> means "a Movie that
    will arrive eventually." We store the IOU and wait for it.
  - initState(): Think of this like the "on app open" hook. It runs once when
    the screen first appears. We use it to kick off the first movie fetch.
  - _refresh(): When the user taps the refresh button, this runs setState().
    setState() is magic—it tells Flutter "something changed, redraw the
    screen." We swap the old IOU note for a brand new one, triggering a new
    fetch.

FutureBuilder<Movie>:
  - This is the most important widget on the screen.
  - It watches the _movieFuture IOU note.
  - While waiting → show the loading spinner (CircularProgressIndicator).
  - If it failed → show the wifi-off icon and a Retry button.
  - If it succeeded → show the MovieCard with the data.


================================================
 PART 4: THE PIZZA PLATE (widgets/movie_card.dart)
================================================
This is the "presentation box." It takes a Movie object and makes it look
gorgeous on the screen. It knows nothing about the internet or JSON—that's
not its job.

CONSTRUCTOR:
  - movie: The Movie object to display.
  - onRefresh: A "callback." This is a slot for a function. The card itself
    doesn't know HOW to refresh; it just calls whatever function is passed
    to it (which is _refresh() from main.dart).

THE LAYOUT (build method):
  Container (the outer card):
    - Color: Dark navy (#1A1A2E) with a shadow. This is the card background.
    - borderRadius: Rounds the corners.

  Row (the header): Two things side by side.
    LEFT: The Type Badge.
      - We check: is details.type == 'series'? 
      - If yes, show a purple badge that says "📺 SERIES."
      - If no, show a pink badge that says "🎬 MOVIE."
    RIGHT: Duration + Refresh button.
      - isSeries? Show "X Season(s)". Otherwise show runtime (e.g., "142 min").
      - GestureDetector: Wraps the refresh icon. When you tap it, it calls
        onRefresh() (which triggers the _refresh() in main.dart).

  Image.network (the poster):
    - Loads the poster from the internet URL.
    - loadingBuilder: Shows a spinner WHILE the image is downloading.
    - errorBuilder: If the image URL is broken, show a broken-image icon.

  Text (title): Big, white, bold.
  Text (year): Smaller, grey.
  Divider: A subtle horizontal line.
  Text (plot): The story summary in light grey.

THE KEY LESSON: 
  The card doesn't DO anything by itself. It just DISPLAYS. The engine
  (main.dart + ApiService) does all the work. This separation is called
  "Single Responsibility Principle." Each piece has one job. 🏆
